# Task 2: интернет-магазин

Простое Flask-приложение с тестовым каталогом товаров.

## Запуск

```bash
python -m pip install -r requirements.txt
python app.py
```

Сервис запускается на `http://localhost:5000`.

## API

- `GET /api/products` — возвращает список товаров в JSON.
- `GET /api/products?limit=2` — ограничивает количество товаров. Допустимое значение `limit`: целое число от 1 до 100.

Каждый запрос к эндпоинту записывается в журнал на уровне `INFO`. Некорректный `limit` возвращает HTTP 400 и записывается на уровне `ERROR`.
